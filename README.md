## Deploy to GitHub Pages

To publish this site:

1. Create a GitHub repository and push this folder.
2. Go to **Settings** → **Pages**.
3. Select **Deploy from a branch** as source.
4. Choose `main` branch and `/ (root)` folder, then save.
